CONTENT POLICY (NON-NEGOTIABLE)
-------------------------------

printed typos as printed. Content-level changes go into all four languages.

TOOLING & WORKFLOW (proofread method)
-------------------------------------
- Dump stored KN per chapter; spawn parallel read-only reviewers (~6 pages each) that
  report: KEY | exact stored snippet -> exact print text.
- Apply with a per-chapter script: parse the JS file, apply edits only when the
  anchor occurs exactly once in that key, replace the single line (match with
  l.trimStart().startsWith(JSON.stringify(key)+': ')), re-parse, assert 702 keys, write.
- Mixed quote pairs are normalised to ASCII ' by regex; avagraha stored as ಽ; ಋ printed
  like ಖು is stored as ಖು; stored '|' left alone.
- Then: python3 build-bundle.py; git add -A; git commit; git push origin main;
  republish the artifact.
